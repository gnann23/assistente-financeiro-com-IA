# assistente-financeiro-com-IA

Este é o projeto final da trilha, que consolida os aprendizados em IA, Python, dados e UX em uma única experiência: um assistente financeiro conversacional que ajuda o usuário a entender produtos bancários e simular decisões financeiras simples, de forma clara, segura e personalizada.

O app roda em uma interface de chat (Streamlit) e não depende de nenhuma API externa paga — o entendimento da mensagem do usuário é feito com técnicas de NLP clássicas (TF-IDF + similaridade de cosseno), o que torna o projeto leve, gratuito e fácil de rodar localmente.
